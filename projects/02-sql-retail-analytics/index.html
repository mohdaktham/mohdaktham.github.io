Retail sales analytics in SQL

A national retailer wants to know where profit is actually made, which discounting destroys margin, and which customers are worth retention spend. Seven SQL queries answer it.

Data: Superstore retail dataset, 9,994 order lines from 2015 to 2018.

SQL, SQLite, CTEs, Window functions, Python

The question

Where is profit actually made, which discounting behaviour destroys margin, and which customers are worth retention spend?

What I did

  • Normalized a flat 21-column CSV into a 4-table relational schema (customers, products, orders, order_items) with indexes.
  • Wrote 7 analytical queries covering year-over-year growth, profitability ranking, discount-loss diagnosis, 12-month cohort retention, RFM customer segmentation and shipping lag.
  • Scripted the whole run: one script builds the database from the raw file, another executes every query and exports each result as a CSV.

What I found

  • Revenue grew from $484K in 2015 to $733K in 2018, up 29.5% and 20.4% in the last two years, while profit margin improved from 10.2% to 12.7%.
  • Tables lose $17.7K despite heavy discounting (26% on average). Bookcases and Supplies also run negative. Recommendation: cap Table discounts at 15%.
  • Copiers are the hidden star: only 8th in revenue but first in profit, $55.6K at a 37% margin.
  • RFM segmentation found 82 at-risk customers averaging $4,444 in lifetime sales who haven't ordered in about 200 days, the best win-back target.
  • The 12-month repeat-purchase rate for the 2015 cohort is 69%, and rises for later cohorts.

SQL techniques used

Joins across a normalized schema, CTEs, the window functions LAG, RANK, ROW_NUMBER and NTILE, conditional aggregation, date arithmetic with julianday, and HAVING filters.

Run it

pip install pandas
python build_db.py      # builds superstore.db from superstore.csv
